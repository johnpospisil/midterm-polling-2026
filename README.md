# How Wrong Were the Polls? The 2026 Midterms

This project compares every public 2026 Senate, governor and House poll with the certified results. It asks how far off the polls were, whether they all missed in the same direction, and whether newer polling methods did better. It also compares the polls with the final forecasts from public forecasting models.

Status: in progress. A preliminary "first look" based on called races is planned for about November 24, 2026, and the final post-mortem for about December 18, after states certify their results.

## Reproduce

```bash
uv sync
make test
make all
```
